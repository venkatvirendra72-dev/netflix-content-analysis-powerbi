# Netflix Content Analysis Dashboard

An interactive Power BI dashboard analyzing global Netflix catalog trends, format distributions, and geographic production hubs.

## Key Insights & Metrics
- **Catalog Volume:** Analyzed 8,700+ total titles across 88 countries.
- **Format Distribution:** 69.7% Movies vs. 30.3% TV Shows.
- **Top Production Markets:** High concentration led by the United States, India, and the United Kingdom.
- **Time-Series Growth:** Tracks rapid catalog expansion from early releases to peak additions.

## Tech Stack & Tools
- **Platform:** Microsoft Power BI Desktop
- **Data Transformation:** Power Query
- **Metrics & Measures:** DAX

## How to Run Locally
1. Download or clone this repository.
2. Install [Microsoft Power BI Desktop](https://powerbi.microsoft.com/desktop/).
3. Open the `.pbix` file to interact with the report.
